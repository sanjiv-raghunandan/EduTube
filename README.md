# EduTube

EduTube is a local, end-to-end RAG (Retrieval-Augmented Generation) assistant built for programming education content from YouTube. It downloads audio, transcribes videos, cleans and chunks transcripts, indexes them in a vector database, and answers user questions with grounded context.

## What It Does

-   Ingests educational YouTube videos into a searchable knowledge base.
-   Uses local embeddings and vector search for semantic retrieval.
-   Generates answers with source-grounded context.
-   Provides a Streamlit chat interface with source visibility.
-   Includes an offline accuracy evaluation pipeline to measure performance.

## Core Architecture

1.  **Data Ingestion**:
    -   `downloadaudio.py`: Downloads video audio.
    -   `extracttranscript.py`: Extracts transcripts with Whisper.
    -   `cleantranscript.py`: Cleans and chunks transcripts.
2.  **Retrieval Layer**:
    -   `ragdb.py`: Builds and queries a ChromaDB vector store with local embeddings.
3.  **Assistant Layer**:
    -   `assistant.py`: Handles RAG orchestration and prompt construction.
4.  **Frontend**:
    -   `app.py`: A Streamlit chat UI with controls for the assistant.
5.  **Evaluation**:
    -   `accuracytests`: A suite for offline accuracy testing of the RAG pipeline.

## How to Test the Project

### Prerequisites

-   Python 3.10+
-   FFmpeg installed and available in your system's PATH.
-   Ollama installed and running.
-   Required local models pulled in Ollama:
    -   `nomic-embed-text` (for embeddings)
    -   Custom Trained Model: A `llama3.2-3b-instruct` model fine-tuned via Unsloth on a Google Colab T4 GPU, utilizing a golden dataset generated by NotebookLM (or the base `llama3.2` as a fallback for generation).

### Installation

1.  **Install Python dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
2.  **Start the Ollama service** if it's not already running.
3.  **Pull the required models:**
    ```bash
    ollama pull nomic-embed-text
    ```
4.  **Load the custom model:** This project uses a custom model (`edutube-llama`). Make sure to build and load your custom model into Ollama.

### Running the End-to-End Pipeline

1.  **Add YouTube Links**:
    -   Add your URL in `yt.py` and run it to extract youtube video links into a txt file.
2.  **Download Audio**:
    -   Run `downloadaudio.py`:
        ```bash
        python ragdb/downloadaudio.py
        ```
3.  **Transcribe Audio**:
    -   Run `extracttranscript.py`:
        ```bash
        python ragdb/extracttranscript.py
        ```
4.  **Clean and Chunk Transcripts**:
    -   Run `cleantranscript.py`:
        ```bash
        python ragdb/cleantranscript.py
        ```
5.  **Build the Vector Database**:
    -   Run `ragdb.py`:
        ```bash
        python ragdb/ragdb.py
        ```
6.  **Launch the App**:
    -   Run `app.py`:
        ```bash
        streamlit run app.py
        ```

### Running Accuracy Tests

To evaluate the performance of the RAG pipeline, run the evaluation entrypoint:

```bash
python accuracytests/accuracy.py
```

The test results will be saved in the results directory, including:

-   `evaluation_stats.json`: A summary of the evaluation metrics.
-   `evaluation_details.json`: Detailed results for each test case.

#### How Accuracy Is Measured

The project uses a local, embedding-based evaluation method. The key metrics are:

-   **Semantic Similarity**: Compares the generated answer to the expected answer.
-   **Context Relevance**: Measures how relevant the retrieved context is to the question.
-   **Answer Relevance**: Assesses how relevant the generated answer is to the question.

All three metrics are computed using cosine similarity over `nomic-embed-text` embeddings.
